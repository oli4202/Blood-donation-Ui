# Blood Donation UI - Live Test

Flutter UI implementation of the Blood Requests screen according to the live test specifications.

## Screen Overview
- **Header**: Centered "Blood Requests"
- **Blood Request Cards**:
  - Vertical red accent bar on the left edge (`#E53935`)
  - Top row:
    - `"URGENT"` badge tag with soft pink background
    - Blood drop icon with unit count (e.g., `3 Units`, `2 Units`)
  - Title: Bold blood group requirement (`O- Blood Needed`, `O+ Blood Needed`)
  - Location: Outlined location pin icon with hospital address (`Khulna City Medical College Hospital, KDA Ave...`)
  - Full-width `"View Details"` button in dark slate/navy (`#1E293B`)
- **Responsive Layout**: Centered card container with responsive constraints.

## Running the Code
Run using Flutter:
```bash
flutter run exam.dart
```
or
```bash
flutter run main.dart
```
